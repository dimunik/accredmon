# Аккредитационный мониторинг

Браузерный калькулятор для ввода показателей образовательной программы и расчёта баллов. Вычисления выполняются на странице в браузере.

**[Открыть в браузере](https://dimunik.github.io/accredmon/)**

## Разделы

| Раздел | Показатели | Порог итога |
|---|---:|---:|
| Бакалавриат / Специалитет | АП1–АП8 | 70 баллов |
| Магистратура | АП2–АП7 | 60 баллов |
| Среднее профессиональное образование (СПО) | АП1–АП7 | 25–40 баллов, в зависимости от условий программы |

В магистратуре АП1 и АП8 отключены. В каждом разделе отображаются поля ввода, рассчитанные значения и баллы по показателям, общий результат и сравнение с порогом. Цветовая индикация помогает различать результаты показателей и итог.

## Расчёт СПО

Для расчёта порога выберите оба условия:

1. Предусмотрен ли программой демонстрационный экзамен.
2. Основание приёма: среднее общее или основное общее образование.

| Основание приёма | Экзамен не предусмотрен | Экзамен предусмотрен |
|---|---:|---:|
| Среднее общее образование | 25 | 30 |
| Основное общее образование | 35 | 40 |

До выбора обоих условий таблицы показателей СПО скрыты, а порог не определён. АП3 применяется при приёме на базе основного общего образования; АП4 — если предусмотрен демонстрационный экзамен.

## Работа с данными

- Числовые значения и отметки в полях пересчитываются при изменении. Для дробных чисел используйте запятую, например `12,5`.
- Если для раздела в браузере ещё нет сохранённых значений, поля открываются пустыми.
- Введённые значения и условия расчёта СПО автоматически сохраняются в `localStorage` браузера. Сервис не отправляет их на сервер. Сохранение зависит от настроек браузера; очистка данных сайта или запрет локального хранилища может удалить или сделать недоступными сохранённые значения.
- Кнопка «Очистить значения» очищает текущий раздел и условия СПО после подтверждения.
- «Экспорт в PDF» открывает окно печати браузера для текущего раздела. В нём выберите сохранение в PDF; для страницы рекомендуется альбомная ориентация.
- Резервная копия в формате JSON включает данные всех разделов, условия СПО и открытый раздел. При загрузке файл проверяется, а замена сохранённых значений выполняется только после подтверждения. Для сохранения копии браузер должен поддерживать `showSaveFilePicker()`; если поддержка отсутствует, сайт покажет сообщение и файл не сохранит.

## Запуск

Откройте опубликованную страницу: <https://dimunik.github.io/accredmon/>.

Чтобы запустить копию локально, скачайте проект и откройте `index.html` в браузере. Для обычного использования установка зависимостей и сборка не нужны; каталоги `css/` и `js/` должны находиться рядом с `index.html` в исходной структуре проекта.

## Важно

Сервис носит справочно-информационный характер и не является официальным ресурсом уполномоченных органов. Расчёт не заменяет официальные требования и решения; актуальность данных и применимость результата необходимо проверять самостоятельно.
